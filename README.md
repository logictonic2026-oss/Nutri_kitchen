# Nutriserve Industrial Kitchen

A responsive, buildless website using the supplied logo and website content, with a kitchen theme in forest green, cream and mustard. Serve `dist` with any static HTTP server.

The redesign adds section reveals, restrained image parallax, a reading-progress line, a moving flavour ribbon with a pause control, keyboard-accessible meal tabs, and a sticky catering-planning sequence. It preserves native scrolling and respects reduced-motion preferences. Meal enquiries preselect the chosen service in the form. Image sources and generation prompts are documented in `ASSETS.md`.

The enquiry form validates the visitor's details and prepares an email to `sale.nutriserve@gmail.com`. It does not send or store enquiries. Phone links, map search, mobile navigation, and the copy-enquiry fallback work without a backend.

Content decisions: included snacks from the poster; used the poster's email spelling; omitted unapproved draft reviews and the unconfirmed numeric kitchen-capacity claim. The hero uses the supplied poster image as an illustration.
