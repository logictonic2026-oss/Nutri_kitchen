# Nutriserve Industrial Kitchen

A responsive, buildless website using the supplied logo, meal-poster illustration, and website content. Serve `dist` with any static HTTP server.

The enquiry form validates the visitor's details and prepares an email to `sale.nutriserve@gmail.com`. It does not send or store enquiries. Phone links, map search, mobile navigation, and the copy-enquiry fallback work without a backend.

Content decisions: included snacks from the poster; used the poster's email spelling; omitted unapproved draft reviews and the unconfirmed numeric kitchen-capacity claim. The hero uses the supplied poster image as an illustration.
