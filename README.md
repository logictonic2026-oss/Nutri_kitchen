# Nutriserve Industrial Kitchen

A responsive, buildless website using the supplied logo and website content, with a kitchen theme in the brand's cocoa and mustard, food photography and clear menu-board typography. Serve `dist` with any static HTTP server.

The redesign adds two focused image reveals, restrained image parallax, a reading-progress line, keyboard-accessible meal tabs with 220ms photo crossfades, and a sticky catering-planning sequence. It preserves native scrolling and respects reduced-motion preferences. Meal enquiries preselect the chosen service in the form. Buttons and mobile inputs use 48px targets; mobile body and input text is 16px. The continuous decorative ticker was replaced with a readable cuisine band. Image sources and generation prompts are documented in `ASSETS.md`, and the skill-guided design plan is in `DESIGN.md`.

The enquiry form validates the visitor's details and prepares an email to `sale.nutriserve@gmail.com`. It does not send or store enquiries. Phone links, map search, mobile navigation, and the copy-enquiry fallback work without a backend.

Content decisions: included snacks from the poster; used the poster's email spelling; omitted unapproved draft reviews and the unconfirmed numeric kitchen-capacity claim. The hero uses the supplied poster image as an illustration.
